# Installation Guide

Welcome to NKL-4ever Engine!, This guide will explain the planned installation process and how to prepare your environment to work with the engine.

## Requirements
* A compatible operating system.
* Haxe development environment.
* HaxeFlixel framework and required dependencies.
* Git for repository management.
* Additional tools may be required depending on the platform.

## Getting the Source Code

1. Open the NKL-4ever Engine GitHub repository.
2. Download or clone the repository.
3. Extract the source files if necessary.
4. Open the project using your preferred development environment.

## Building the Engine

The build process may require additional dependencies and configuration. 
Build instructions will be expanded as development progresses.

## Android Support

Android compatibility is planned. Installation and storage instructions will be documented as the Android implementation develops.

## Development Status

NKL-4ever Engine is currently under development. Installation procedures, dependencies and platform support may change.
