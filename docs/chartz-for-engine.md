## Installation

1. Download the desired chart mod.
2. Extract the mod files.
3. Move the mod folder into the appropriate NKL-4ever mods directory.
4. Launch the engine.
5. Select the mod and enjoy!

## Troubleshoot

If you experience performance issues:
* Make sure you're using a recommended engine version.
* Check whether your device has enough available resources.
* Verify that all mod files are correctly installed.
* Check the mod's documentation for additional requirements.
