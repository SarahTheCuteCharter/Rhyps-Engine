# Chart Editor

The NKL-4ever Chart Editor is intended to provide tools for creating, editing and managing custom Friday Night Funkin' charts.

## Planned Features

* Custom chart creation.
* Multiple difficulty levels.
* Extended chart support.
* Custom note types.
* Event editing.
* BPM and scroll speed configuration.
* Chart preview and playback.
* Support for large and complex charts.

## Chart Compatibility

NKL-4ever aims to support existing chart formats while introducing additional possibilities for custom charts. Compatibility may vary depending on the chart format and engine version.

## Performance

The chart system is being designed with performance in mind, especially for charts containing extremely large numbers of notes.

## Custom Charts

Users will be able to organize and manage their charts through the engine's file system.

## Development Status

The Chart Editor is under development. Features and compatibility are subject to change.
